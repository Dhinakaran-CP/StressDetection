SSVB-CASA-AIS Model Details

Self-Supervised Verified-Baseline Cross-Attention Stress Architecture with Identity Suppression

Key Parameters

  • Accuracy: 67.23%
  • F1-Score: 59.09%
  • ROC-AUC: 0.7311

Methodology Summary

This model integrates standard Leave-One-Subject-Out (LOSO) cross-validation with high-capacity unimodal sequence encoders and gradient reversal suppression (GRL). Self-supervised pretraining is done contrastively inside each modality stream to extract user-independent representations before task-specific fine-tuning.

VBC-CASA-IS Model Details

Verified-Baseline Contrastive Cross-Attention Stress Architecture with Identity Suppression

Key Parameters

  • Accuracy: 63.72%
  • F1-Score: 55.06%
  • ROC-AUC: 0.7044

Methodology Summary

VBC-CASA-IS implements dual-representation inputs, processing raw absolute features alongside user-relative baseline deviations to help the model learn physiological variance. A custom Quality Gate rejects artifacts, and cross-attention is quality-masked to down-weight unreliable signals. Optimization is regularized via a joint contrastive pretraining penalty to align modalities under temporal step dimensions.
