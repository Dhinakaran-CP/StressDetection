🌐 Deployed Cloud Infrastructure

Frontend (Vercel): React SPA with automatic HTTPS encryption (mandatory for browser webcam & microphone permissions).

Backend (Render): Flask + PyTorch + SocketIO engine running on Python 3.10 WSGI (Gunicorn Eventlet).

⚡ Core Capabilities

Realtime Tracking: 468 3D webcam face landmarks + Librosa vocal prosody audio analysis.

Sub-5ms Inference: Fast classical Random Forest & CNN+GRL inference engines.

💡 Problem & Value Proposition

Monitors cognitive and emotional stress in real time without lab equipment or invasive tracking, solving single-modality failure modes through multimodal fusion.

Deployment Infrastructure Stack

Production setup on Vercel & Render
Slide 03
  • Frontend Layer (Vercel): Built with React 19, Tailwind CSS, and Framer Motion. Configured with vercel.json SPA proxy rules to ensure client-side routing works smoothly.
  • Media Streaming Security: Vercel provides native SSL/TLS HTTPS encryption, allowing browsers to grant webcam and microphone permissions safely.
  • Backend Engine (Render): Python 3.10.12 WSGI application powered by gunicorn with eventlet async workers for high-concurrency WebSocket support.
  • Build Speed Optimization: Configured PyTorch CPU wheel index (torch-cpu) reducing dependency download size from 900MB to 80MB, cutting build time by 90%.

Active Model Selection (CNN+GRL & RF)

Dual-mode selection in production web app
Slide 04

🧠 CNN + GRL (Primary Deep Champion)

Architecture: 1D-CNN baseline with Gradient Reversal Layer (GRL).

Adversarial Subject De-identification: Penalizes identity memorization (λ = -0.02), forcing model to learn pure stress indicators.

Size: ~23,000 lightweight parameters.

🌲 Random Forest (Production ML Ensemble)

Architecture: Multi-tree decision ensemble with balanced class weighting.

Performance: 77.46% Accuracy under 15-fold Leave-One-Subject-Out validation.

Footprint: Sub-3ms CPU execution latency, 2.5 MB weights.

Real-time Feature Pipeline & Modalities

Domain-specific non-invasive indicators
Slide 05
  • Facial Modality (MediaPipe WASM 468 Points): Computes 18 scale-invariant indicators including Eye Aspect Ratio (EAR), Brow Descent, Masseter Tension Proxy, and Lip Compression.
  • Vocal Modality (Librosa Audio Spectrum): Extracts Mel-Frequency Cepstral Coefficients (MFCCs 1–13), Fundamental Frequency (F0) pitch variance, Spectral Flux, and Pause Rate.
  • Physiological Telemetry: Captures Heart Rate Variability (HRV - SDNN, RMSSD), Respiration Rate, and Galvanic Skin Response (GSR/EDA) Phasic spikes.
  • Sampling Optimization: Client-side windowing processes landmarks at 15 FPS to conserve CPU and network bandwidth.

Security & Production Hardening

Privacy preservation & API security
Slide 09
  • Zero Raw Video Storage: Webcam images and microphone streams are processed transiently in RAM and discarded immediately to preserve privacy.
  • Thread-Safe Temporary Files: Replaced static temporary filenames with tempfile.NamedTemporaryFile to prevent race conditions during concurrent user uploads.
  • Secret Admin Auth Guard: Protected sensitive admin routes (/api/admin/*, restart, shutdown) using X-Admin-Key header verification.
  • Secure API Key Headers: Passed Gemini API key via x-goog-api-key headers to prevent key exposure in HTTP access logs.
